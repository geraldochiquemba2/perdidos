# 🏛️ Economia com História

> Uma plataforma educacional premium e interativa que conecta a história econômica global ao aprendizado moderno, através de gamificação de alto nível, discussões comunitárias e um design visual de tirar o fôlego.

---

## ✨ Design & Estética Premium

A interface do **Economia com História** foi projetada para encantar e engajar o estudante desde o primeiro segundo. Inspirada na elegância das aplicações de elite, o design utiliza:
*   🖤 **Sleek Dark Mode**: Fundo em grafite profundo (`#0F0F0F`) que reduz o cansaço visual.
*   🩸 **Cores Curadas e Sofisticadas**: Detalhes em vermelho carmesim imperial (`#3A0310`) e acentos em ouro rose luxuoso (`#E8B4B8`).
*   🔮 **Efeitos Glassmorphism**: Painéis e inputs translúcidos com desfoque de fundo (*backdrop blur*) que dão profundidade e modernidade.
*   🎭 **Micro-Animações Dinâmicas**: Transições suaves e responsivas alimentadas por `Motion` que respondem ao toque e cursor do usuário, tornando a navegação viva.

## 🚀 Principais Módulos do Aplicativo

### 1. 📖 Jornadas de Conhecimento (Explore)
Descubra trilhas interativas sobre grandes momentos econômicos mundiais:
*   **Ouro e Impérios**: Explore como o metal precioso moldou as maiores rotas comerciais e impérios africanos.
*   **Revolução Industrial**: O motor do vapor às transformações modernas do capitalismo.
*   **Mercados Africanos**: A transição milenar do escambo ao comércio digital contemporâneo.

### 2. 🏆 Panteão de Elite (Rankings)
Um sistema de gamificação completo para incentivar o progresso dos alunos:
*   Tabelas de classificação com avatares estilizados e badges de prestígio.
*   Destaques de elite para quem lidera o acúmulo de prestígio acadêmico.

### 3. 🧠 Quizzes Interativos
Avalie seu aprendizado através de testes rápidos, dinâmicos e projetados com feedback visual imediato para fixação dos conceitos históricos.

### 4. 🗣️ Fórum de Debates
Uma área comunitária onde os estudantes podem discutir tópicos profundos, debater artigos, criar tópicos de estudo e trocar opiniões de forma organizada.

### 5. 🛡️ Painel Administrativo de Elite
Um painel gerencial robusto e seguro projetado para administradores:
*   **Controle de Conteúdo**: Ferramentas para curadoria e edição de temas, trilhas e novas lições.
*   **Gestão de Usuários**: Moderação de acessos, listagem inteligente e suspensão se necessário.
*   **Métricas em Tempo Real**: Gráficos analíticos de engajamento do usuário usando `Recharts`.

## 🛠️ Stack Tecnológica

O projeto foi construído usando tecnologias modernas e otimizadas para alto desempenho:
*   ⚛️ **Core**: React 18.3 & TypeScript para tipagem estática e segurança.
*   ⚡ **Build Tool**: Vite 6 para inicialização instantânea no desenvolvimento e compilação ultra-rápida.
*   🎨 **Estilização**: Tailwind CSS v4 para um design consistente baseado em tokens, e componentes baseados em Radix UI.
*   🎬 **Animações**: Motion (Framer Motion v12) para animações e transições fluidas de tela.
*   📊 **Gráficos**: Recharts para visualização elegante de dados no painel administrativo.
*   🧩 **Ícones**: Lucide React para iconografia limpa e moderna.

## 🖥️ Executando o Projeto Localmente

Siga os passos abaixo para rodar o ambiente de desenvolvimento em sua máquina local:

### 1. Instalar as dependências:
```bash
npm install
```

### 2. Rodar o servidor de desenvolvimento local:
```bash
npm run dev
```
Após executar o comando acima, o projeto estará rodando no endereço fornecido pelo terminal (geralmente [http://localhost:5173](http://localhost:5173)).

### 3. Compilar para produção:
```bash
npm run build
```
