# Economia com História

Uma plataforma educacional premium e interativa que conecta a história econômica global ao aprendizado moderno, através de gamificação de alto nível, discussões comunitárias e uma interface visual de alta qualidade.

---

## Design e Estética

A interface do Economia com História foi desenvolvida para engajar o estudante por meio de um design moderno e limpo. O projeto adota os seguintes padrões visuais:

- **Sleek Dark Mode**: Fundo em grafite profundo (#0F0F0F) para conforto visual prolongado.
- **Paleta de Cores**: Detalhes em vermelho carmesim imperial (#3A0310) e acentos em ouro rose (#E8B4B8) para uma identidade marcante.
- **Glassmorphism**: Painéis e inputs translúcidos com desfoque de fundo (backdrop blur) para sensação de profundidade.
- **Micro-animações**: Transições suaves e interações alimentadas pela biblioteca Motion para enriquecer a navegação.

---

## Principais Módulos do Aplicativo

### 1. Jornadas de Conhecimento (Explore)
Trilhas de conteúdo dedicadas a grandes episódios da história econômica:
- **Ouro e Impérios**: Estudo sobre o metal precioso e o comércio nas rotas africanas.
- **Revolução Industrial**: A transição do vapor e as engrenagens do capitalismo moderno.
- **Mercados Africanos**: A evolução comercial das trocas de escambo às soluções digitais contemporâneas.

### 2. Panteão de Elite (Rankings)
Sistema de progresso e gamificação para incentivar a constância dos alunos:
- Tabelas de liderança atualizadas com perfis e badges de prestígio.
- Diferenciação visual para alunos em destaque.

### 3. Quizzes Interativos
Avaliação do aprendizado com testes objetivos e dinâmicos, fornecendo feedback de desempenho imediato.

### 4. Fórum de Debates
Área comunitária focada na troca de ideias, onde alunos podem debater artigos, criar tópicos de estudo e compartilhar dúvidas.

### 5. Painel Administrativo
Área gerencial robusta projetada para gestão e moderação:
- **Controle de Conteúdo**: Curadoria, edição de lições e atualização de temas.
- **Gestão de Usuários**: Listagem, pesquisa inteligente e moderação de contas.
- **Métricas de Engajamento**: Gráficos analíticos de atividade integrados com Recharts.

## Stack Tecnológica

O projeto adota tecnologias modernas e otimizadas para escalabilidade e desempenho:

- **Core**: React 18.3 & TypeScript.
- **Build Tool**: Vite 6 para inicialização e empacotamento ágeis.
- **Estilização**: Tailwind CSS v4 para sistema de design utilitário consistente e componentes estruturados com Radix UI.
- **Animações**: Motion (Framer Motion v12).
- **Gráficos**: Recharts para modelagem de relatórios administrativos.
- **Ícones**: Lucide React.

## Fundamentação Pedagógica

## Executando o Projeto Localmente

Siga os passos abaixo para rodar o ambiente de desenvolvimento local:

### 1. Instalar as dependências
```bash
npm install
```

### 2. Iniciar o servidor de desenvolvimento
```bash
npm run dev
```
O projeto estará disponível no endereço indicado no terminal (geralmente http://localhost:5173).

### 3. Gerar a build de produção
```bash
npm run build
```
